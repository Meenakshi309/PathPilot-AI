# PathPilot AI — UI Wireframes

## Design Direction

Modern AI SaaS

The interface should be:
- Clean
- Modern
- Spacious
- Professional
- AI-focused
- Easy to navigate

---

# 1. Dashboard

## Purpose

Give the user a quick overview of their learning progress and today's study activities.

## Layout

- Top navigation bar
  - PathPilot AI logo
  - Dashboard
  - Goals
  - Planner
  - AI Assistant
  - User profile

- Welcome section
  - Greeting
  - Short motivational message

- Progress overview
  - Today's study time
  - Completed sessions
  - Current streak
  - Overall progress

- Today's study session
  - Subject/topic
  - Start time
  - Duration
  - Start Session button

- AI Insights
  - AI-generated learning suggestion
  - Recommended next action

- Upcoming sessions
  - Next scheduled study sessions

---

# 2. Goals

## Purpose

Allow users to create, manage and track their learning goals.

## Layout

- Page heading
  - "My Learning Goals"
  - Create Goal button

- Goal cards
  - Goal title
  - Description
  - Progress percentage
  - Progress bar
  - Target date
  - Topics/skills

- Goal actions
  - View
  - Edit
  - Delete

- Empty state
  - Message when no goals exist
  - Create your first goal button

---

# 3. Planner

## Purpose

Allow users to schedule and manage study sessions.

## Layout

- Page heading
  - "Study Planner"
  - Add Session button

- Calendar
  - Month/week/day navigation
  - Scheduled study sessions

- Selected session details
  - Topic
  - Date
  - Start time
  - Duration
  - Status

- Session actions
  - Mark as completed
  - Edit
  - Delete

- Missed session indicator
  - Shows missed study sessions
  - Option to reschedule

---

# 4. AI Study Assistant

## Purpose

Provide an AI-powered learning assistant that helps users understand topics and plan their learning.

## Layout

- Page heading
  - "AI Study Assistant"

- Chat area
  - User messages
  - AI responses

- Suggested prompts
  - Explain a topic
  - Create a study plan
  - Give me practice questions
  - Recommend learning resources

- Context section
  - Current learning goal
  - Current topic

- Input area
  - Message input
  - Send button

- AI response features
  - Explanation
  - Examples
  - Study recommendations
  - Source/resource references

---

# Navigation Flow

Dashboard
   ↓
Goals
   ↓
Planner
   ↓
AI Study Assistant

Users can navigate between all four sections using the main navigation bar.

# Dashboard Visual Layout

## Overall Structure

The Dashboard uses a left sidebar navigation and a main content area.

### Left Sidebar

- PathPilot AI logo
- Dashboard
- Goals
- Planner
- AI Assistant
- Settings
- Profile

### Main Content

#### Header

- Welcome message
- Short description
- User profile/avatar

#### Progress Overview

Four metric cards:

1. Study Time
2. Completed Sessions
3. Day Streak
4. Overall Progress

#### Main Section

Two cards displayed side by side:

- Next Study Session
- AI Insight

#### Upcoming Sessions

A list/table showing:

- Time
- Topic
- Status
